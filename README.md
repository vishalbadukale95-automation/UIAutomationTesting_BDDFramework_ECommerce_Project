**UI Automation Testing - BDD Framework**

**Overview** 
This project is an automated UI testing framework for an E-Commerce application. 
The framework is developed using Java and follows the Behavior Driven Development (BDD) approach.

**Technologies Used**
- Java
- Selenium WebDriver
- Cucumber BDD
- TestNG
- Maven
- Maven Surefire Plugin
- Page Object Model (POM)
- PageFactory
- Cucumber Hooks
- Cucumber TestNG Runner
- XPath
- Chrome Browser
- ChromeDriver
- Extent HTML Reports
- Extent PDF Reports
- Git
- GitHub
- Git Bash
- Eclipse IDE

**Framework Features**
1. BDD testing using Cucumber
2. UI automation using Selenium WebDriver
3. Test execution using TestNG
4. Maven-based project and dependency management
5. Page Object Model (POM)
6. PageFactory for web element initialization
7. Cucumber Hooks for setup and teardown
8. Data-driven testing
9. Screenshot capture for test execution
10. Extent Reports for test reporting
11. Parallel test execution
12. Cucumber Feature Files for BDD scenarios
13. Step Definitions for implementing feature scenarios
14. XPath-based web element identification
15. Cross-browser testing using Chrome/ChromeDriver

**Project Structure**
1. src - Source code, step definitions, runners and supporting classes
2. AllFeatureFiles - Cucumber feature files
3. ExtentReports - Test execution reports
4. Screenshot - Screenshots captured during test execution
5. test-output - Test execution output
6. pom.xml - Maven project configuration and dependencies

  **How to Run**
1. Clone the repository.
2. Import the project into Eclipse as a Maven project.
3. Update Maven dependencies.
4. Configure the required browser and test environment.
5. Execute the Cucumber/TestNG test runner.
